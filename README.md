# 🌦️ Weather

A simple and modern weather dashboard for checking live weather conditions around **Howrah, West Bengal**.

The website uses the **Open-Meteo Weather API** to provide weather information without requiring an API key.

---

## ✨ Features

- 🌡️ Current temperature
- 💧 Humidity
- 🌧️ Current rainfall
- 💨 Wind speed
- 🌡️ Today's maximum temperature
- 🥶 Today's minimum temperature
- 🌅 Sunrise time
- 🌇 Sunset time
- ☔ Rain probability
- 📅 7-day weather forecast
- 📍 Multiple location selection
- 🌙 Dark-themed interface
- 📱 Responsive design for mobile and desktop
- 🔄 Automatic weather updates every 5 minutes
- 🔑 No API key required

---

## 📍 Available Locations

The website currently supports:

- **Sial Danga**
- **Maju**
- **Jagatballavpur**
- **Panchla**

Users can select a location from the dropdown menu, and the weather data automatically changes according to the selected coordinates.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Weather API

No frameworks or external JavaScript libraries are required.

---

## 🌐 Weather API

This project uses:

**Open-Meteo**

Open-Meteo provides weather forecasts using geographical coordinates and does not require an API key for the free/non-commercial API.

Weather data is provided under the **CC BY 4.0** license, so attribution is included in the website footer.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/weather.git
````

### 2. Open the project

Go into the project folder:

```bash
cd weather
```

### 3. Run the website

Simply open:

```text
index.html
```

in your browser.

You don't need to install any packages or configure an API key.
